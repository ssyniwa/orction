# 🎴 レリック・オークション：禁忌のセリ市

『レリック・オークション：禁忌のセリ市』は、怪しげな裏社会のセリ市を舞台に、ライバルたちと競り合いながら至高のレリック（古代遺物・呪物）を集め、一攫千金やコレクションコンプリートを目指すダークファンタジー＆サイバーパンク風の経営シミュレーションゲームです。Python（Streamlit）で開発されています。

---

## 🌟 ゲームの特徴

* **激しいリアルタイム・オークション**
  * 3人の個性的なライバル（堅実派・撹乱派・執着派）とリアルタイムで競り合い。
  * 「鑑定チケット」を使ってアイテムの表向きの評価と「真の価値」、そして「呪い」の有無を見抜け！
* **スリリングな闇市とリスク管理**
  * 所持金がピンチの時は、「闇バイト」「闇金の借入」「違法人体実験」などのハイリスクな資金調達手段を活用。
  * 呪われたアイテムや借金の利息によるペナルティ、計画的な「借金返済」が攻略の鍵を握ります。
* **充実のコレクション＆ミュージアム要素**
  * 一度獲得したアイテムは、売却しても全30種類の「レリック・コレクション全集」に永久に記録されます。
  * お気に入りのアイテムを「プライベート・ミュージアム」に永久保存すれば、クリア時の評価に強力なボーナスが加算されます。
* **多彩なマルチエンディング**
  * 最終的な資産額だけでなく、ミュージアムの展示数や所持している呪物の数、借金の状況などによって結末が分岐するマルチエンディングを採用。

## 🚀 導入・起動方法

1. リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone [https://github.com/your-username/relic-auction.git](https://github.com/your-username/relic-auction.git)
   cd relic-auction
   ```
2. 必要なライブラリ（Streamlitなど）をインストールします。

   ```bash
    pip install streamlit
    ```
3. アプリを起動します。

    ```bash
    streamlit run app.py
    ```
## 📖 遊び方・ゲームループ

1. オークション会場: 毎日出品されるアイテムをチェックし、必要に応じて鑑定を行ってからオークションを開始します。ライバルと競り合って目当てのレリックを落札しましょう。

2. 所持品・闇市: 落札したアイテムを転売したり、コレクターに高値で売り込んだり、ミュージアムに寄贈します。資金が足りない場合は闇市でリスクを冒して資金を稼ぎます。

3. ゲームクリア: 全日程を終えた時の資産状況やプレイスタイルに応じて、専用のイラスト付きエンディングへと分岐します。
